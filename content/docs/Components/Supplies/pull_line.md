## Overview

Pull line (commonly called pull tape, or by the genericized brand name Mule Tape) is the flat, woven polyester tape installed inside empty conduit runs to pull conductors, cable, or fiber through afterward — either left pre-installed for future use, or pulled in at the time cable is being run so the next pull has a line already in place. It's distinct from a few other conduit-pulling tools it's sometimes confused with:

- **Fish tape** — a stiff, reeled steel or fiberglass tape pushed through the conduit itself to fish a line through; suited to short, straight runs, but can kink or bind on longer or bendier runs.
- **Jet line** — a lighter cord-like line, sometimes blown through conduit with compressed air; workable for short, straight runs, but a round profile can cut into PVC conduit walls under load on bends.
- **Twisted rope pulling line** — round, twisted nylon or polyester rope, used for the heaviest pulls (very high tensile loads) where pull tape's flat profile isn't the limiting factor.

Flat pull tape is the standard choice for most conduit runs because its flat profile spreads load and reduces friction against the conduit wall compared to a round line, especially through bends, and it's typically pre-lubricated to reduce pulling friction further.

![](/images/pull-line-example.png)

Pull line is selected based on:

1. **Tensile strength** — rated in pounds, matched to the anticipated pulling load with margin; light-duty (roughly 400-1,250 lb) suits small conduit and telecom/data runs, while heavy-duty (3,000-6,000+ lb) suits larger electrical/power cable pulls. As a rule of thumb, select a rating meaningfully above the estimated load rather than cutting it close.
2. **Width** — narrower tape (1/2") for light-duty pulls and smaller conduit; wider tape (3/4"-1") for heavy-duty pulls, generally correlating with higher tensile strength.
3. **Footage markings** — most professional-grade tape is pre-printed with sequential footage markings, letting the installer measure conduit run length as the tape is pulled in and track remaining tape on the reel without a separate tape measure.
4. **Conduit size/fit** — tape width must clear the conduit's inside diameter with room for the tape to move freely alongside any other pre-installed lines.
5. **Packaging/reel** — lightweight plastic reels for portable, smaller-quantity use; wooden or heavier reels for long-length or bulk supply on larger jobs.

## Naming Convention

When identifying pull line for vendor ordering, use the following naming structure, listing attributes in this order:

```
(WIDTH) (STRENGTH) (MARKING) Pull-Line
```

### Example Names

- `1/2" 1250lb Sequential-Footage Pull-Line`
- `5/8" 2500lb Sequential-Footage Pull-Line`
- `3000lb Sequential-Footage Pull-Line`
- `1in 6000lb Sequential-Footage Pull-Line`
- `1/2in 1250lb Unmarked Pull-Line`

### Convention Notes

| Descriptor   | Explanation                                                                                                                                                                                              |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `(WIDTH)`    | The tape's width (e.g., 1/2", 5/8", 3/4", 1"), sized to conduit diameter and correlating generally with tensile strength. Default to 3/4".                                                               |
| `(STRENGTH)` | The tape's rated tensile/breaking strength in pounds (e.g., 1250lb, 2500lb, 3000lb, 6000lb); select a rating meaningfully above the anticipated pulling load, not just matched to it. Default to 2500lb. |
| `(MARKING)`  | Sequential-Footage (pre-printed length markings for measuring runs as the tape is pulled) or Unmarked (plain tape with no printed markings). Default to Unmarked.                                        |

## Typical Units of Measure

|Unit|Typical Use|
|---|---|
|**Reel**|Standard individual unit, sold by total footage (commonly **500-5,000 ft per reel**, depending on width/strength).|
|**Box**|Boxed reel packaging for job-site portability, especially for lighter-duty/smaller-footage tape.|
|**Case**|Distributor bulk quantity for large commercial or underground infrastructure projects; multiple reels per case.|

### Ordering Help

- Always size **tensile strength with margin above the anticipated pulling load** — cable weight, run length, and the number and radius of bends all add resistance beyond the cable's static weight alone, so cutting the rating close to the estimated load risks a mid-pull failure.
- Confirm **width fits the conduit** alongside anything else already inside it — a tape too wide for the available clearance will bind rather than pull freely.
- **Sequential footage markings** are worth specifying by default on any run where knowing exact conduit length matters for documentation, future planning, or billing — the cost premium over unmarked tape is minor relative to the value of an accurate as-built measurement.
- Pull tape is meant to be **installed and left in place** for future use as often as it's used for an active pull — when ordering for new conduit installs, plan quantity assuming the tape stays in the conduit rather than being consumed and discarded per job.
- For the **heaviest pulls** (beyond standard pull tape's rated range) or pulls through unusually harsh conditions, confirm whether a twisted rope pulling line is more appropriate than tape — this page covers flat pull tape specifically, not twisted rope.
