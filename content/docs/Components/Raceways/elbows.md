## Overview

The purpose of an elbow is to turn and route conduit into another direction, continuing the protection and space optimization that the conduits supply. This is done using a degree of bend with a radius of the bend, all of which should comply with NEC based on the conduit type and wiring being pulled through. 

Much like the conduit types, elbows can be fashioned in the same conduit type with some variations on how the elbow connects to the conduit pieces. The prefabrication shop can fashion conduit elbows to whatever job site requirements are.

Refer to the Conduit component page for more information on conduit types. Elbows come in those same types.

## Naming Conventions

```
SIZE TYPE (MATERIAL) (SCHEDULE) DEGREE (RADIUS) (END) Conduit-Elbow
```

| Descriptor   | Explanation                                                                                                                                                                                                                                                                                                                  |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `SIZE`       | Includes the trade size of the conduit in inches ("). Whole number with partial measurements should include a hyphen to keep measurements searchable.                                                                                                                                                                        |
| `TYPE`       | Refers to the type of conduit (EMT, IMC, PVC, etc.)                                                                                                                                                                                                                                                                          |
| `(MATERIAL)` | Indicates the material the conduit should be made of. Most of the conduit types have a standard default material, so unless the material needs to be specific, this portion of the convention can be left off. For metal conduits, assume Steel if left off. If specified, use the full material name.                       |
| `(SCHEDULE)` | Refers to the schedule number if the type of conduit is PVC. There are two standards: Schedule 40, the most commonly purchased, and Schedule 80, which is thicker and stronger in pressured conditions. Put in (Schedule-40, Schedule-80) form.                                                                              |
| `DEGREE`     | Defines the degree of bend that the elbow should utilize (45-Degree, 90-Degree, 22-1/2-Degree, etc).                                                                                                                                                                                                                         |
| `(RADIUS)`   | Defines the radius size in inches of the bend itself. There are a set of standard radius sizes that depend upon the size of the elbow itself. If left off, assume the standard radius sizing for the size and material of the elbow. If specially ordered, put the radius sizing here in inches (18-Radius, 24-Radius, etc.) |
| `(END)`      | Refers to the ending of the conduit elbow. PVC is typically ordered in (Bell-End).                                                                                                                                                                                                                                           |

## Typical Units of Measure

|Unit|Typical Use|
|---|---|
|**Each (EA)**|Standard unit for pricing and ordering — elbows are almost always ordered individually or in small case quantities, not by length.|
|**Box/Case**|Bulk packaging for smaller trade sizes (1/2" through 1-1/4"), typically packed **6, 8, or 10 per carton** depending on size, material, and manufacturer.|
|**Pallet**|Distributor/contractor bulk quantity for large trade sizes (2" and up) or high-volume underground/duct bank projects; quantity per pallet varies significantly by size.|

## Ordering Help

- Always specify **trade size, angle, and radius class** (standard, long-radius/sweep, or a specific radius in inches) together — a "90" alone is not a complete order, since standard and long-radius elbows of the same trade size are not interchangeable and serve different code and wire-pull requirements.
- Confirm whether the application requires a **factory elbow** rather than a field bend — factory elbows are strongly preferred (and often effectively required by practicality) for trade sizes 2" and larger, tight/confined spaces, and any run where field bending equipment cannot achieve the specified minimum radius.
- For **PVC**, confirm bell-end vs. plain-end configuration, since bell ends are standard for solvent-weld assembly and plain ends require a separate coupling.
- For **underground duct bank work**, specify long-radius "DB" sweeps by name rather than assuming a standard elbow will meet the minimum bend radius — this is a common source of rejected inspections.
