## Overview

A gutter end (also called an end plate, end cap, or closure plate) is the flat steel or nonmetallic plate that closes off the open end of a gutter box run — see the Gutter Boxes page. A gutter box section ships open on both ends so sections can be joined together into a run of the needed length; wherever a run terminates rather than continuing to another section or into equipment, a gutter end is required to close that opening and maintain the enclosure's rating (keeping dust, moisture, and incidental contact out, and preserving the "complete enclosure for the contained conductors" construction NEC 366 requires).

Because a gutter box is quoted and ordered by the section/length rather than as a single complete assembly, the gutter end is routinely a separate line item that's easy to overlook when pricing a run — every open end in the finished layout needs one, and a run with unused open ends (common when the exact final connection point isn't confirmed until later in the job) still needs to be temporarily or permanently closed to protect the installed conductors.

![](/images/gutter-end-example.png)

Gutter ends are selected based on:

1. **Size fit** — matched exactly to the gutter box's cross-sectional dimensions (e.g., 6"x6", 8"x8"); not a universal or adjustable fit, since it must seat against the gutter body's specific opening.
2. **Knockout configuration** — With-Knockouts (for a conduit or cable entry directly through the end of the run) or Without-Knockouts/blank (a plain closure with no entry point).
3. **Material** — matched to the gutter box's own material (steel, stainless steel, or nonmetallic) to maintain corrosion resistance and, for metal gutters, bonding continuity.
4. **NEMA/Type rating** — matched to the gutter box's rating (Type 1, 3R, 4, 4X, 12) so the closure doesn't become the weak point in an otherwise properly-rated enclosure run.
5. **Attachment style** — most gutter ends are a bolted/screwed flat plate; some product lines offer a hinged or lay-in style matching the gutter's own cover style for runs expected to be reopened.

## Naming Convention

When identifying gutter ends for vendor ordering, use the following naming structure, listing attributes in this order:

```
SIZE RATING (MATERIAL) (KNOCKOUTS) Gutter-Box
```

### Example Names

- `4"-4" NEMA-1 Steel With-Knockouts Gutter-End`
- `8"-8" NEMA-3R Gutter-End`
- `6"-6" NEMA-4X Aluminum Blank Gutter-End`

### Convention Notes

| Descriptor    | Explanation                                                                                                                                                        |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `SIZE`        | The end plate's dimensions, matched exactly to the gutter box's cross-section (e.g., 4x4in, 6x6in, 8x8in).                                                         |
| `RATING`      | The NEMA/Type rating (e.g., Type-1, Type-3R, Type-4X, Type-12), matched to the gutter box's own rating so the closure doesn't compromise the run's overall rating. |
| `(MATERIAL)`  | Steel (standard, matched to metal gutter boxes), Stainless-Steel (corrosive/washdown environments), or Nonmetallic (matched to nonmetallic gutter boxes).          |
| `(KNOCKOUTS)` | With-Knockouts (for a conduit/cable entry through the closed end) or Blank (plain closure, no entry point). Default to Blank.                                      |

|Unit|Typical Use|
|---|---|

### Ordering Help

- Always **count every open end in the finished gutter layout** when quoting — since gutter box is ordered by section, it's easy to price the run length but forget the end closures, especially at a run's final unconnected end.
- Confirm **size, material, and rating match the gutter box exactly** — a gutter end isn't a universal accessory; it has to seat against and maintain the rating of the specific gutter product it's closing.
- Specify **With-Knockouts only where an actual conduit or cable entry is planned** at that end — a blank plate is the simpler, more reliably sealed choice everywhere else.
- For a run where the **final connection point isn't confirmed yet**, order a blank gutter end to temporarily close and protect the open run, with the understanding it may be removed later if the run is extended or connected to additional equipment.
- Since this is a small, easy-to-miss line item, it's worth **cross-checking the gutter end quantity against the gutter box quantity/layout** as a standing step before finalizing any quote involving gutter box.
