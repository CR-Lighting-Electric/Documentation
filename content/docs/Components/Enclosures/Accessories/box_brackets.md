## Overview

A box bracket is a stamped-steel bracket that spans the gap between two studs and holds one or more square boxes (or mud rings) at a set height and spacing, so a run of boxes can be rough-installed quickly and uniformly before drywall. It is built for the 4" square and 4-11/16" square boxes covered on the Square Boxes page, and it is typically ordered alongside the Mud Rings that finish the opening. These can commonly be called **"License Plate Brackets"** in the field due to the rectangular shape they are commonly ordered in.

![](/images/box-bracket-example.png)

This page is distinct from the Box Supports page. Box Supports covers the broader family of mounting hardware (single-stud brackets, bar hangers, offset brackets, floor stands). Box Brackets covers the between-stud brackets made specifically for square-box and ring assemblies, and it is organized around three choices that drive the order: how many boxes the bracket carries, which box size it fits, and what stud span it covers. Adjustable bar hangers appear in both product spaces; use this page when the job is a run of square boxes, and the Box Supports page when it is a single box or a ceiling hanger.

Box bracket types:

- **Fixed-position bracket** — a bracket cut for one stud spacing, with the box positions already located along it. Catalog families offer a version for 16" stud bays and a version for 24" bays; the 24" version generally carries one more box position than the 16" version. Boxes are secured with bendable latch tabs or screws, and some designs have a keyhole pattern that lets the box turn 90° and stay in place with the ring removed.
- **Slider bracket** — a bracket on which the box slides along its length, so a single box can be placed at any point between studs before it is locked down.
- **Adjustable (telescoping) bracket** — a bracket that extends to fit non-standard stud spacing, with a stated adjustment range (for example, about 11" to 18" or 15-3/4" to 26" on common bar hanger models, and 10-3/8" to 18" on a common brace).

Box brackets are selected based on:

1. **Stud span** — 16" or 24" for the fixed-position versions; for an Adjustable bracket, the model's stated range must cover the actual stud-to-stud dimension.
2. **Gang count (box positions)** — the number of boxes or rings the bracket carries. Fixed-position models commonly carry 3 positions on the 16" version and 4 positions on the 24" version; confirm the position count in the catalog for single-box and slider models. This counts boxes on the bracket, not devices: each box can itself take a multi-gang ring.
3. **Box size** — 4" square, 4-11/16" square (the box the field calls a "5 square"), or a bracket that accepts both. Some manufacturers also list a true 5" square box, and a 4" ring can be used on any of the box sizes.
4. **Stud type** — wood or metal studs; confirm the bracket is made for the framing in use.
5. **Box depth** — the bracket must clear the box depth in use (commonly 1-1/2" and 2-1/8", and 2-1/2" on some models).
6. **Material and finish** — sheet steel, galvanized.

## Naming Convention

When identifying box brackets for vendor ordering, use the following naming structure, listing attributes in this order:

```
GANG BOXSIZE-Box (SPAN-Span) (MATERIAL) Box-Bracket
```

### Example Names

- `3-Gang 4"-Box Galvanized-Steel Box-Bracket`
- `4-Gang 4"-Box Box-Bracket`
- `1-Gang 4-11/16"-Box  Box-Bracket`
- `2-Gang 4"-Box 24"-Span Box-Bracket`
- `1-Gang 4-11/16"-Box Adjustable-Span Box-Bracket`
- `3-Gang 4-11/16"-Box Adjustable-Span Galvanized-Steel Box-Bracket`

### Convention Notes

| Descriptor     | Explanation                                                                                                                                                                                                                                                                 |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GANG`         | The number of boxes or rings the bracket carries (1-Gang, 2-Gang, 3-Gang, 4-Gang). Catalogs often call these "positions." It counts boxes on the bracket, not devices; a ring on one box can still be multi-gang.                                                           |
| `BOXSIZE`      | 4in, 4-11/16in (the field "5 square"), or 4-or-4-11/16in for a bracket that accepts both. Where a manufacturer lists a true 5in square box, specify 5in and confirm it in the catalog.                                                                                      |
| `(SPAN)`       | 16" or 24" for a fixed-position bracket cut for that stud spacing, or Adjustable for a telescoping bracket. For Adjustable, confirm the model's stated range (for example, about 11in to 18in or 15-3/4in to 26in) against the real stud-to-stud dimension.                 |
| `(MATERIAL)`   | Galvanized-Steel (standard sheet-steel finish). Other materials can be ordered, but default to Galvanized-Steel.                                                                                                                                                            |
| Catalog number | Vendor catalogs (e.g., Orbit, Southwire/Garvin, nVent Caddy, Eaton, Hubbell RACO) also carry their own part numbers; provide both the plain-language name and the catalog number when known, since box positions, depth range, and stud type are brand- and model-specific. |

## Typical Units of Measure

|Unit|Typical Use|
|---|---|
|**Each (EA)**|Occasional use for a single bracket on a small job.|
|**Pack**|Common contractor packaging, typically **25 per pack** for fixed-position brackets and **50 per pack** for adjustable hangers.|
|**Case**|Distributor bulk quantity for larger new-construction projects.|

### Ordering Help

- Confirm **stud spacing (16" or 24" on-center)** before ordering a fixed-position bracket; a 16" bracket will not span a 24" bay. An Adjustable bracket avoids the mismatch on jobs with mixed framing.
- When a request says **"5 square,"** confirm whether it means the 4-11/16" square box (the usual meaning in the field) or a true 5" square box before ordering; the two are different sizes.
- Count **boxes, not devices**, when picking the gang count: a 3-position bracket holds three boxes, and each can take a multi-gang ring.
- Match the **bracket's depth range to the box depth** actually being installed; a bracket sized for 1-1/2" and 2-1/8" boxes may not suit a deeper box.
- Confirm the bracket is made for the **stud type in use** (wood or metal) and add the matching Mud Rings to the same order so the opening finishes correctly.
- Order brackets as a **companion line item to the square box order**, not as an afterthought; they are inexpensive but hold up a rough-in when missing.
