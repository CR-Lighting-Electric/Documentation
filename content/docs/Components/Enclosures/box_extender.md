## Overview

A box extension (called a spark ring on the field, also sometimes a goof ring) is a listed extender used to bring an electrical box's opening forward, flush with a finished wall or ceiling surface, when the box ends up recessed too far back — commonly after adding a wall finish layer (extra drywall, tile, backsplash, paneling) or where a box was set before the final wall thickness was known. Unlike the Extension Rings page (scoped to 4" and 4-11/16" square boxes and the box-fill volume distinction under NEC 314.16), "box extension" and "spark ring" are the general field terms covering this same function across **all box shapes** — round, octagon, single-gang device boxes, and square — not just square junction/device boxes. Where the Extension Rings page is about square-box-specific volume-marking, this page covers the broader family of shape-matched flush-depth extenders.

![](/images/box-extender-example.png)

The governing requirement is NEC 314.20 (Flush-Mount Boxes), which sets how far a box front is allowed to sit back from the finished surface:

- **Noncombustible surfaces** (concrete, tile, gypsum board) — the box front can be set back no more than 1/4" from the finished surface.
- **Combustible surfaces** (wood) — the box front must be flush with, or project out from, the finished surface — no setback allowed at all.

A box recessed beyond these limits is a code violation, and a spark ring is the standard fix — rather than cutting out and resetting the box, the ring is installed on the box front to bring the opening forward to the correct depth. This makes spark rings a common corrective/retrofit item as much as a planned one, often needed after a later trade (flooring, tile, cabinetry) changes the finished surface thickness beyond what was assumed at rough-in.

Box extensions are selected based on:

1. **Box shape fit** — Round, Octagon, Single-Gang (rectangular device box), or Square, matched to the specific box being extended; not universal across shapes.
2. **Extension depth** — how far the ring brings the box forward, commonly available up to around 1-1/2" in adjustable or tapered designs, or in fixed increments; selected based on the actual setback distance measured in the field.
3. **Material** — Plastic (nonmetallic, common for device box extenders) or Metal (steel, common for round/octagon boxes, especially where the box itself is metal and bonding continuity matters).
4. **Listing** — must be UL listed for the purpose; an improvised or unlisted spacer is not a code-compliant substitute for a listed spark ring.
5. **Gang count** — for device box extenders, Single, Double, Triple, or Quad, matched to the box being extended.

## Naming Convention

When identifying box extensions for vendor ordering, use the following naming structure, listing attributes in this order:

```
GANG (SHAPE) (DEPTH-Depth) (KNOCKOUTS-KO) (MATERIAL) Box-Extender
```

### Example Names

- `1-Gang 1"-Depth Box-Extender`
- `2-Gang 1-1/2"-Depth Metal Box-Extender`
- `1-Gang 1/2"-KO Plastic Box-Extender`

### Convention Notes

| Descriptor    | Explanation                                                                                                                                                                                                                                                                                                                                   |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GANG`        | 1-Gang, 2-Gang, 3-Gang, 4-Gang (for Single-Gang device box extenders) or omit (for Round, Octagon, or Square boxes, where gang count doesn't apply the same way).                                                                                                                                                                             |
| `SHAPE`       | Round, Octagon, Single-Gang (rectangular device box), or Square — matched to the specific box shape being extended. Defaults to Octagon for spark rings.                                                                                                                                                                                      |
| `(DEPTH)`     | The extension's depth or maximum adjustable range (e.g., 1/2", 3/4", 1", 1-1/2"), matched to the actual setback distance measured in the field. Default to 1-1/2"-Depth.                                                                                                                                                                      |
| `(KNOCKOUTS)` | The predominant knockout size on the box (e.g., 1/2", 3/4", 1"); boxes commonly include multiple knockout sizes, so confirm the full knockout pattern against the specific product when more than one size is needed. Include all knockout sizes. Use "Special" for the typical 1/2"-3/4" Knockout pattern. Defaults to Blank (no knockouts). |
| `(MATERIAL)`  | Plastic (common for device box extenders) or Metal (common for round/octagon boxes, especially where bonding continuity with a metal box matters). Defaults to Plastic.                                                                                                                                                                       |

### Ordering Help

- Always confirm **box shape fit** before ordering — a spark ring is shape-specific (round, octagon, single-gang, square), not a universal fit across box types.
- Measure the **actual setback distance** in the field before ordering, and compare it against NEC 314.20's limits (1/4" max on noncombustible surfaces, flush/projecting required on combustible surfaces) to confirm an extension is actually required and to select the right depth.
- Confirm **UL listing** for the specific product — this is what makes a spark ring a code-compliant fix rather than an improvised spacer; don't substitute washers, shims, or other non-listed material to bring a box forward.
- Box extensions are frequently needed as a **retrofit/corrective item** after a later trade changes finished surface thickness (added tile, extra drywall layer, thicker flooring) — it's worth keeping a stock of common sizes on hand for finish-stage corrections rather than treating this purely as a planned rough-in item.
- Where the setback is **larger than any standard spark ring can correct**, or the box itself was set at the wrong depth to begin with, resetting the box is the more reliable fix — a spark ring corrects a moderate setback, not a fundamentally mis-set box.
