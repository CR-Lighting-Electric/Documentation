## Overview

A masonry box is a heavy-gauge welded steel device box built to be set directly into concrete block, brick, or poured concrete construction — where a standard stud-mounted device box has nothing to fasten to. It's set in place as the wall is built up (block-by-block or in the concrete form) rather than mounted after the fact, so it has to be rigid and durable enough to survive being handled, positioned, and having masonry material worked in around it without deforming.

![](/images/masonry-box-example.png)

Masonry boxes are selected based on:

1. **Construction type:**
    - **Solid** — a fixed, one-piece welded box at a set gang count; used where the device layout is final and won't change.
    - **Gangable** — has removable side plates, letting individual single-gang box sections be joined together in the field to build up a wider multi-gang box as needed; more flexible for field changes to device count.
2. **Gang count** — solid boxes are commonly available from 1-gang up through 6-gang; gangable boxes can be chained together to reach higher gang counts as needed.
3. **Depth** — commonly available in 2-1/2" and 3-1/2" depths, sized for the box-fill volume needed (more conductors, devices, or a low-voltage/power partition all call for the deeper option) and for the actual masonry wall thickness being built.
4. **Knockout pattern** — masonry boxes typically include concentric knockouts (CKO) in a range from 1/2" to 3/4", positioned to allow conduit entry from multiple angles/sides since the box's final orientation in the wall is set before conduit is stubbed to it.
5. **Device partitions** — some multi-gang masonry boxes include an internal barrier separating low-voltage/signal wiring from power wiring within the same multi-gang opening, reducing interference between the two.
6. **Brackets** - a number of bracket types can be affixed to the side of the masonry box for easy install in various locations such as mounting to studs, joists, and other mounting points.

## Naming Convention

When identifying masonry boxes for vendor ordering, use the following naming structure, listing attributes in this order:

```
GANG (CONSTRUCTION) (DEPTH-Depth) (PARTITION) (KNOCKOUTS-KO) (BRACKET) Masonry-Box
```

### Example Names

- `1-Gang Solid 2-1/2"-Depth 1/2"-KO Masonry-Box`
- `2-Gang Solid 3-1/2"-Depth Masonry-Box`
- `1-Gang Gangable 2-1/2"-Depth Masonry-Box`
- `3-Gang Solid 3-1/2"-Depth Partitioned Masonry-Box`
- `1-Gang Gangable 3-1/2"-Depth Masonry-Box`
- `2-Gang Masonry-Box`
- `4-Gang F-Bracket Masonry-Box`

### Convention Notes

| Descriptor       | Explanation                                                                                                                                                            |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GANG`           | Single, Double, Triple, Quad, etc. — the number of devices the box (or chained gangable sections) is sized to hold.                                                    |
| `(CONSTRUCTION)` | Solid (fixed one-piece box at a set gang count) or Gangable (removable side plates, chainable in the field to build up gang count). Default to Solid.                  |
| `(DEPTH)`        | The box's interior depth, commonly 2-1/2" or 3-1/2", sized to box-fill volume needs and the masonry wall thickness. Default to 2-1/2"-Depth.                           |
| `(PARTITION)`    | Partitioned (includes an internal barrier separating low-voltage/signal from power wiring within a multi-gang box) or No-Partition (standard, single wiring category). |
| `(KNOCKOUTS)`    | Size of the knockout holds surrounding the masonry box. Defaults to 3/4".                                                                                              |
| `(BRACKET)`      | Bracket type affixed to the side of the masonry box for fastening to various locations (F, C, D, S, VMS, etc.) i.e. F-Bracket, C-Bracket, etc.                         |

### Ordering Help

- Choose **Gangable construction** when the final device count isn't locked in yet or may change during rough-in — it's easier to add sections in the field than to swap out a solid box already set in masonry.
- Confirm **depth against the actual wall thickness and box-fill needs** before the box is set — unlike a stud-mounted box, a masonry box is difficult and disruptive to swap out once it's built into the wall.
- Masonry boxes are set **during wall construction**, not retrofitted afterward — coordinate box placement and conduit stub-outs with the masonry crew's schedule, since correcting a box position after the wall is built typically means cutting into finished masonry.
- For installations combining **low-voltage and power devices** in one multi-gang opening, specify a partitioned box to keep the wiring categories separated within the same enclosure.
- Confirm **knockout size and pattern** against the conduit sizes and entry angles needed, since the box's orientation is fixed once set and can't be easily adjusted afterward.
