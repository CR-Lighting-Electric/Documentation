## Overview

A rod coupling (rod coupling nut) is a long, fully-threaded hex or round coupling used to join two lengths of all-thread rod end-to-end into a single continuous run, or to step down between two different rod diameters at a connection point. The basic **coupling nut** is already listed as one of the functional families on the Nuts page; this page covers the rod-coupling product line specifically — its size/reduction options, length patterns, and material choices — since it's a distinct, frequently-ordered line item alongside all-thread rod rather than a general-purpose nut pulled off the shelf.

![](/images/rod-coupling-example.png)

Rod coupling types:

- **Standard rod coupling** — both ends threaded to the same size, used to extend a run of all-thread rod to a longer overall length (e.g., joining two 10 ft sections of 1/2-13 rod into a 20 ft run).
- **Reducing rod coupling** — each end threaded to a different size (named larger-thread-first, e.g., 3/8-16 x 1/4-20), used to transition between two different rod diameters at a single connection point, such as stepping down from a heavier structural rod to a lighter rod for a final hanger drop.
- **Long-pattern coupling** — an extended-length version of the standard coupling, providing more thread engagement on each side for higher-load connections or where additional adjustment range is needed before final tightening.
- **Swivel/eye coupling** — a coupling with a pinned or swiveling eye on one end instead of a second threaded connection, used to transition from threaded rod to a cable, turnbuckle, or clevis connection, common on seismic cable-restraint bracing runs.

Rod couplings are selected based on:

1. **Type** — Standard for same-size extension, Reducing for a size transition, Long-Pattern for extra thread engagement/load capacity, or Swivel/Eye where the run transitions to cable or a pinned connection.
2. **Size** — matched to the mating rod diameter(s); a reducing coupling is specified with the larger thread size listed first (e.g., 3/8-16 x 1/4-20).
3. **Material** — Zinc-Plated-Steel (standard indoor), Hot-Dip-Galvanized (exterior/damp locations), or Stainless-Steel (304 general corrosion resistance, 316 for marine/coastal), matched to the same environment considerations as the all-thread rod and nuts it connects.
4. **Load path/application** — general extension work is fine with a standard coupling at the rod's own grade; seismic bracing, structural anchoring, and life-safety suspended systems should be checked against the project's engineering documents for the specific coupling type and grade required.

## Naming Convention

When identifying rod couplings for vendor ordering, use the following naming structure, listing attributes in this order:

```
SIZE(xTO-SIZE) (TYPE) (MATERIAL) Rod-Coupling
```

### Example Names

- `1/2"-13 Standard Zinc-Plated-Steel Rod-Coupling`
- `3/8"-16x1/4"-20 Reducing Zinc-Plated-Steel Rod-Coupling`
- `5/8"-11 Long-Pattern Hot-Dip-Galvanized Rod-Coupling`
- `1/2"-13 Standard Stainless-Steel Rod-Coupling`
- `3/8"-16 Swivel-Eye Stainless-Steel Rod-Coupling`
- `1/2"-13x3/8-16 Reducing Hot-Dip-Galvanized Rod-Coupling`

### Convention Notes

| Descriptor       | Explanation                                                                                                                                                                                                                                                                                                      |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `SIZE(xTO-SIZE)` | The mating rod thread size (e.g., 1/2"-13); for a Reducing coupling, both sizes are given with the larger thread listed first, separated by an "x" (e.g., 3/8"-16x1/4"-20).                                                                                                                                      |
| `(TYPE)`         | Standard (same-size extension), Reducing (size transition), Long-Pattern (extended thread engagement for higher load or extra adjustment), or Swivel-Eye (transitions to cable/turnbuckle/clevis connection). If there is only one size, default to Standard. If there is a reducing size, then assume Reducing. |
| `(MATERIAL)`     | Zinc-Plated-Steel (standard indoor), Hot-Dip-Galvanized (exterior/damp locations), or Stainless-Steel (304 general corrosion resistance, or specify 316 for marine/coastal). Default to Zinc-Plated-Steel.                                                                                                       |

### Ordering Help

- Always list the **larger thread size first** on a reducing coupling to match standard vendor catalog convention and avoid an ordering mix-up (e.g., 3/8-16x1/4-20, not 1/4-20x3/8-16).
- For **seismic bracing and life-safety-related suspended systems**, confirm coupling type and grade against the project's engineering documents rather than defaulting to a standard-duty coupling — a swivel/eye coupling in particular is often a project-specific, engineered connection point rather than a stock substitution.
- Match **material to the connected rod and nuts**, not just to the coupling in isolation — mixing finishes (e.g., a stainless coupling on galvanized rod) can create a galvanic pairing worth avoiding in damp or corrosive environments.
- A **long-pattern coupling** is worth specifying over standard wherever a connection will see higher load or repeated vibration — the added thread engagement on each side improves the joint's holding capacity over a standard-length coupling.
- Rod couplings are a **frequent companion line item to all-thread rod orders** — when ordering rod for a job that requires field splicing (long hanger/bracing runs, multi-section drops), include the expected coupling quantity and type on the same order.
